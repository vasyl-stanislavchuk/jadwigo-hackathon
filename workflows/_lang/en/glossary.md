# English glossary

The math words US grades 1 to 3 use, as Jadwigo writes them for a child, and the gloss a parent
reads when a word needs one. A line uses the question's own word; when the question has none, it
uses the word here.

| Idea | For the child | For the parent | Never |
| --- | --- | --- | --- |
| addition | `add`, `plus`, `+`, `in all` | addition | `sum up` to a child |
| subtraction | `subtract`, `take away`, `minus`, `−` | subtraction | |
| multiplication | `times`, `groups of`, `×` | multiplication | `x` or `*` for times |
| division | `divide`, `share equally`, `÷` | division | `/` to a child |
| equal groups | `4 groups of 6` | multiplication as equal groups | |
| rows | `4 rows of 6 dots` | arrays | |
| result | `How many in all?` | | `score` (`checklist.md` en-6) |
| times table | `times table` | multiplication facts | `maths` (`checklist.md` en-2) |
| a row of the table | `the 7s`, `times 7` | multiplying by 7 | |
| tens and ones | `tens`, `ones` | place value | `units` |
| even, odd | `even`, `odd` | | |
| greater, less | `greater than`, `less than`, `>`, `<` | | `bigger` for a number |
| a skill moving | | `coming along` | a level name |
| a skill to watch | | `needs attention` | `weak`, `problem` |

Sources: the Common Core State Standards for Mathematics, grades 1 to 3
([thecorestandards.org/Math](https://www.thecorestandards.org/Math/); "groups of" and "×" from
[3.OA.A.1](https://www.thecorestandards.org/Math/Content/3/OA/)), and Merriam-Webster for
spelling ([merriam-webster.com](https://www.merriam-webster.com/)).
