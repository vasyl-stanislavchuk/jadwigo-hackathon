# Polish glossary

The maths words Polish klasy 1 to 3 use, as Jadwigo writes them for a child, and the gloss a
parent reads when a word needs one. A line uses the question's own word; when the question has
none, it uses the word here.

| Idea | For the child | For the parent | Never |
| --- | --- | --- | --- |
| addition | `dodawanie`, `dodaj`, `+` | dodawanie | `sumowanie` to a child |
| subtraction | `odejmowanie`, `odejmij`, `−` | odejmowanie | |
| multiplication | `mnożenie`, `razy`, `·` | mnożenie | `x` or `*` for times |
| division | `dzielenie`, `podziel`, `:` | dzielenie | `/` or `÷` to a child |
| equal groups | `grupy po 6`, `4 grupy po 6` | mnożenie jako grupy równej wielkości | |
| rows | `rzędy`, `4 rzędy po 6 kropek` | | `wiersze` |
| result | `wynik` of a sum, only inside a question (`Jaki jest wynik?`) | | `wynik` as a score (`checklist.md` pl-5) |
| times table | `tabliczka mnożenia` | tabliczka mnożenia | |
| a row of the table | `mnożenie przez 7` | mnożenie przez 7 | `rząd 7` |
| tens and ones | `dziesiątki`, `jedności` | dziesiątki i jedności | |
| even, odd | `parzyste`, `nieparzyste` | | `nie parzyste` (`checklist.md` pl-9) |
| greater, less | `większe`, `mniejsze`, `>`, `<` | | |
| a skill moving | | `idzie do przodu` | a level name |
| a skill to watch | | `wymaga uwagi` | `słabo`, `problem` |

Sources: the 2017 podstawa programowa for klasy I-III, edukacja matematyczna
([Dz.U. 2017 poz. 356](https://isap.sejm.gov.pl/isap.nsf/DocDetails.xsp?id=WDU20170000356)),
and the words the owner's runs settled in `workflows/jadwigo-lesson-compose/SKILL.md` and
`workflows/jadwigo-report-write/SKILL.md`.
