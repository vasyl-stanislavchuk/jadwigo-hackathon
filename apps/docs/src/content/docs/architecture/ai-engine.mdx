A parent's chat message becomes 1 run, and a run is a chain of steps. A step is 1 call to a Meta
Muse model plus the lesson verbs that call asks for, given to the model as function tools. This
page shows the engine's parts, then one turn through them.

<Diagram name="ai-engine" caption="Queue, step loop, guarded model call, verbs, run events." />

## Parts

The step loop takes 1 step from the queue and builds the model's input: the parent's words, any
photos, and the verbs. It sends that through `GuardedMuse`, which checks the spend cap before the
call and writes 1 ledger row after it, with the run's id as the trace. No call runs without a cap:
the runner refuses to start when the cap is unset.

The loop then runs each verb the model asked for. Every effect is a run event, and the log is the
draft: a verb that changes the lesson writes a new lesson revision. The page folds the events into
the chat and the lesson, so a reload rebuilds the same screen.

## One turn

<Diagram name="runner-turn" />

The API never waits for the model, and a step that runs twice never pays or writes twice: it reuses
a recorded model response, skips a tool whose result exists, and fences every write on the run's
attempt.

## Safety

A verb takes who it acts for from the run row, never from the model's arguments. A learner id from
the model is only a choice inside the family's own data, and the verb checks it. A learner's data,
names included, may reach the Meta model for the parent's own request. Text a child or a photo
wrote goes to the model inside an untrusted-content fence, as data and never as instructions.

The API holds 2 family limits before a run opens: 10 messages a minute, and 10 USD of model spend
per family per UTC day.

## Every verb group

| Group | What it does |
| --- | --- |
| `lesson` | Drafts, shows, edits and checks a lesson. |
| `bank` | Searches the question bank and reads question bodies. |
| `learner` | Reads the family's own learners, goals, skills and reports. |
| `review` | Reviews words a child or parent will read. |
