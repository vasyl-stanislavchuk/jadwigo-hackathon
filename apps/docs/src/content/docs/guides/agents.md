This page is for anyone pointing an AI agent at Jadwigo: what the docs publish for agents, and where
to start.

- [MCP](/mcp/): connect `jw mcp serve` to Claude Code, Codex or Muse Code, then call its tools.
- `/llms.txt`: an index of these docs for a language model.
- `/openapi.json`: the OpenAPI 3.1 document for every route of the API.
- `/mcp-tools.json`: every MCP tool with its input and output schema.
