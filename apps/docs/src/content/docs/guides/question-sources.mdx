This guide is for anyone reading a question from the bank: which sources it holds, and how
`GET /api/v1/questions/{id}` finds a question's body from its id.

A question body's `source` says where the question comes from. The id names the source too, so
the route needs nothing but the id:

- An id that starts with `alfik_`, such as `alfik_2024_k2_q07`, is an Alfik Matematyczny task.
- Any other id, such as `x1a2b3c4`, is a Khan Academy item.

A question from a source shows that source's credit beside its instruction, and the card it opens
names the licence. An Alfik task is a `choose` question: the task's picture as its stem and 5
lettered choices, A to E.
