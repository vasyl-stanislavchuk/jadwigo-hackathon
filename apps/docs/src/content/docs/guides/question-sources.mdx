This guide is for anyone reading a question from the bank: which sources it holds, and how
`GET /api/v1/questions/{id}` finds a question's body from its id.

A question body's `source` says where the question comes from. The id names the source too, so
the route needs nothing but the id:

- An id that starts with `alfik_`, such as `alfik_2024_k2_q07`, is an Alfik Matematyczny task.
- Any other id, such as `x1a2b3c4`, is a Khan Academy item.

A question from a source shows that source's credit beside its instruction, and the card it opens
names the licence. An Alfik task is a `choose` question: the task's picture as its stem and 5
lettered choices, A to E.

## Which questions a set holds

`GET /api/v1/question-sets/{id}` reads one set from a search row's `id`. Its `items.ids` are every
question the set holds, and `items.ready_ids` are, per language, the ones that are lesson-ready.
A lesson takes only a ready id, then reads that question's body by its id.
Its `question_types` are the question types of those ready questions, `problem_types` names
each problem type with its question types, and `ready_types` counts ready questions per language
and type.

## Which question types the bank holds

`GET /api/v1/question-types?grade=1&language=pl` lists the question types the bank holds for a
grade and language: for each, its family, how many sets hold it and how many lesson-ready
questions it has. Leave out `grade` or `language` to list them all. A search narrows to sets
holding a type when its need names `question_types`: `slots.fill_gaps`, a glob such as `group.*`,
a bare family such as `choose` or a bare type such as `multi_select`.
