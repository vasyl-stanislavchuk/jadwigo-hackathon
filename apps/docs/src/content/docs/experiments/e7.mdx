This run tests whether a model can judge a child's own-words answer against criteria written
first, and do it kindly. It's the evidence behind [judging answers](/vision/judging-answers/).

<ExperimentResult id="e7" />

## Question

Given an explain task and its criteria, does a model's verdict agree with a careful human's, and
does its feedback stay kind?

## Setup

The team wrote 8 explain tasks for grades 2 and 3, in Polish and English, such as multiplication
as groups, the rz spelling rule, and why a plant turns yellow. Each task has 2 or 3 criteria,
written before any answer. The team then wrote 80 answers and labelled each one per criterion:
right, partly right, right answer with a wrong reason, off-topic, right but misspelt, or too short.
No text came from a real child. 3 judges saw the same criteria: code alone,
`muse-spark-1.3-contributor` and `muse-wonder-full-1.0`.

## Result

The 2 models agreed with the team's labels on 95.0% and 93.8% of the 80 answers. Both gave a
reason for all 170 criterion verdicts. No feedback line was a bare „wrong", and none ran past 30
words.

## What failed

- **Code alone can't judge.** It only asks for more when an answer is short. It did that on 10
  answers, and only 5 of them were really not there yet.
- **Both models made the same false „wrong"** on 1 borderline answer: a bare list of even numbers
  that shows the rule without saying it.
- **The agreement is with the team, not with teachers.** The answers and labels are the team's
  own. A reason counts as written when it has 3 words or more, and nothing checks that it quotes
  the child.
