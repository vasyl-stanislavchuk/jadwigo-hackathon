This run audits what it cost to make the question bank searchable with Meta models, and how far
a model's draft can be trusted. It's the evidence behind [growing the bank](/vision/growing-the-bank/).

<ExperimentResult id="e4" />

## Question

What did enriching and labelling the bank cost, call by call, and do the models' drafts hold up
under code's checks?

## Setup

Every model call the bank makes goes through 1 client and lands in a ledger: model, tag, seconds,
tokens and USD. Before this run the ledger held 3,249 calls on `muse-spark-1.3-contributor`.
They enriched 143 Khan grade 3 sets and their 2,738 questions, and labelled 215 test needs the
team wrote. A live half then drafted 3 grade 3 sets once each, on `muse-spark-1.3-contributor`
and on `muse-wonder-full-1.0`, with the same prompt. Code checked every draft: a claim whose quote
isn't in its source is dropped, curriculum tags must exist, and no hint may leak.

## Result

Enriching a set costs about $0.018, and a question about $0.00044. Neither model leaked a hint or
an answer. Where the source pins a field down, the 2 models agree: curriculum tags overlap at 0.60
to 0.75.

## What failed

- **Free-chosen keywords barely agree,** at 0.07 to 0.10. That gap is why the pipeline keeps 3
  drafts and a critic, and why every field waits for a person's review.
- **Quotes go missing.** On 1 set, wonder lost 8 of its 16 claims to the quote check. Over the 3
  sets spark kept 42 of 44 and wonder 36 of 46. Code drops a bad claim, so it never reaches a set
  page, but the draft is weaker for it.
- **No person has reviewed the enrichment yet.** Every field is still marked unreviewed.
- **1 draft per model is a reading, not a verdict.** Wonder is also unpriced on this path, so its
  cost is in tokens only.

## Cost

$10.28 for 3,253 calls, the live run included ($0.0128 on spark). Scaled from 143 sets, set and
question enrichment comes to about $26.52 per 1,000 sets, before a person's review.
