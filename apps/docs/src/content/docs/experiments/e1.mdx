This run tests whether code alone can turn 3 weeks of a child's answers into what the child knows.
It's the first step of [the learning loop](/vision/learning-loop/).

<ExperimentResult id="e1" />

## Question

Can code, with no model, fold every first try into a level per skill, a flag when a skill needs
work, and a date to review it, and tell different children apart?

## Setup

The team invented 12 learners, each with a profile such as steady, forgetful, guesser or
weekend-only. Each one has a hidden skill level per topic that grows with a clean first try and
fades over a gap. The run plays 21 days from a pinned clock and seed, so a re-run gives the same
cohort. The 10 skills are real catalogue skills: multiplication rows 2 to 7 and 4 Polish spelling
skills. The fold and the review dates are the product's own code. No real child's data went in.

## Result

Code folded 1,301 first tries, and the profiles came out clearly different. Steady and
perfectionist end with 4 skills at mastered. Forgetful keeps 1 and has 9 flagged. Being right with
help doesn't lift a level: help-heavy answered 104 times and still has 5 skills at attempted.

## What failed

- **The flag fires too often.** A miss in a skill's last 2 tries flags it, so 79 of the 120 skill
  rows are flagged after 3 weeks. Most briefs start with "reteach", which is too long a list for a
  parent to act on.
- **The learners are invented.** The run shows that the code separates profiles the team wrote. It
  doesn't show that the code reads a real child correctly.

## Cost

$0. No model ran, and nothing was written to a database.
