This run prices the happy path: a homework photo in, a playable lesson out. It's the evidence
behind [photo to lesson](/features/photo-to-lesson/).

<ExperimentResult id="e6" />

## Question

What does one lesson cost and how long does it take, from a parent's photo to a lesson a child can
play?

## Setup

The team drew 3 homework worksheets as HTML and rendered each to a photo: multiplication for grade
2, Polish spelling for grade 3, and a shopping word problem for grade 3. Each photo went in as a
parent's message, exactly as the API takes one, and the runner's own engine turned it into a
lesson on a local database with the product's model. The one stand-in is where the photo comes
from: a file here, the uploads bucket on prod. Cost and tokens come from each run's own model
records.

![The invented grade 2 multiplication worksheet: 8 sums, 4 already answered, 1 of them
wrong](../../../assets/experiments/e6/w1-mnozenie.png)

## Result

2 of 3 worksheets became lessons, in 38 to 44 seconds and for about $0.0024 each. Played with the
key's own solution, every step of both lessons graded correct.

## What failed

- **The spelling worksheet got nothing, and no error.** The bank has no Polish spelling questions.
  The next call failed on a missing bank route, and the run ended with nothing shown to the parent.
- **The multiplication draft doesn't compile.** Its help words have the wrong shape, so its play
  graded the draft's own steps, not a compiled lesson. Its check also reported 18 problems and a
  bad skill id, and the lesson card was shown anyway.

So only 1 of the 3 worksheets became a lesson that compiles and plays as a child would see it. A
lesson is cheap, at about a quarter of a cent, but this path isn't reliable yet.

## Cost

$0.0048 for 19 calls across the 3 runs: 162,303 input tokens, 134,386 of them cached, and 8,808
output tokens.

## Every worksheet in the run
