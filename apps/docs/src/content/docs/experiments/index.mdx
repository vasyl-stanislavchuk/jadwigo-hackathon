---
title: Experiments
description: Seven runs on Meta's Muse models that test the vision on invented learners, each with what it showed and what failed.
---

Each experiment asks one question about the vision and answers it with a run, not a promise. All
7 used invented learners, invented homework or invented answers. No real child's data went in.

Read the verdict column first. 4 runs found the idea works, with a catch each, and 3 found where
it does not work yet. Each page states its setup, its result and what failed.

## Every experiment

| Run | Question | Result | Verdict |
| --- | --- | --- | --- |
| [E1](/experiments/e1/) | Can code turn practice into what a child knows? | 12 invented learners over 21 days come out clearly different. 79 of 120 skill rows get flagged, too many. | Works, over-flags |
| [E2](/experiments/e2/) | Can the next lesson be drawn from that? | 11 of 12 learners got a lesson, 1 got none. Fit rated 2.39 of 5. | Not yet |
| [E3](/experiments/e3/) | Can a model write the parent's report from code's facts? | Judges rated accuracy 4.8 of 5, but 1 of 12 reports passed the code check. | Not yet |
| [E4](/experiments/e4/) | Can Meta models index the question bank? | 143 sets and their 2,738 questions were enriched and indexed for search. A new set takes the same steps. | Works |
| [E5](/experiments/e5/) | Does the bank's search test catch a worse index? | It blocks the newer index, which declines fewer questions it should decline. | Gate works, index blocked |
| [E6](/experiments/e6/) | Does a homework photo become a lesson? | 2 of 3 worksheets became lessons in about 40 seconds. 1 of the 2 drafts fails to compile. The spelling worksheet found no questions in the bank. | Partly |
| [E7](/experiments/e7/) | Can a model judge a child's own words? | 2 models agreed with the team's labels on about 95% of 80 invented answers. | Works, on invented answers |
