Jadwigo started with one family: a mum, a dad and their son in the first school grades, with 2
goals his parents set, multiplication and Polish spelling. The homework page was the only plan
anyone had. Making practice that fits it, and then the next practice from what he got wrong, used
to take a private tutor.

## Problem

Learning apps build a course and personalise its pace. Khan Academy moves a child through a shared
course, Duolingo builds a daily streak, and Kahoot and Quizlet run a teacher's set. None of them
starts from this week's homework, and none keeps a parent beside the child.

A lesson built from one child's history was never worth building for one family. With AI, it is.

## The bet

The bet was that a parent's whole job could be 1 photo. Jadwigo reads the homework page, draws
questions from a credited question bank, checks the lesson, and sends the child a link. The child
plays with no sign-in, and every question can say where it came from.

Two rules shaped the rest. Code computes every number about a child, and a model only writes words
from what code counted. A parent says yes before anything changes.

## What got built

In 10 days, from 2026-10-26 to 2026-11-04, the happy path went live on
[app.jadwigo.pl](https://app.jadwigo.pl): photo, lesson, share, play, print.
[What's real](/what-is-real/) lists every part with its status.

Around it sit a chat-first parent app, a question bank of Khan Academy and Alfik sets indexed by
Meta models, a remote MCP server so a parent's own AI app can make lessons, and these docs, which
build their API and MCP pages from the code.

## How it was built

Agents wrote the code: Meta's Muse, OpenAI's Codex and Anthropic's Claude Code each did part of
it. One person, the owner, made the product decisions, planned the work and ran every deploy.

The repo took 878 commits in those 10 days, 872 of them squash-merged pull requests. Each agent
worked in its own copy of the repo on one issue, and a guard refused the unsafe moves: a force
push, a deploy, a change to `main` without review. [Building with
agents](/architecture/building-with-agents/) shows that loop.

## What didn't work

- A lesson drawn from what a child knows fit poorly, at 2.39 of 5 ([E2](/experiments/e2/)).
- Only 1 of 12 parent reports passed the code check ([E3](/experiments/e3/)).
- A spelling worksheet got no lesson and no error, because the bank has no grade 3 spelling yet
  ([E6](/experiments/e6/)).
- Voice was cut early. Children type or tap their answers.

## What's next

The [learning loop](/vision/learning-loop/): each answer becomes what Jadwigo knows about the
child, the next lesson is drawn from it, and the parent gets a short weekly report. Then the family's
class, the school, and anyone who finds it.
