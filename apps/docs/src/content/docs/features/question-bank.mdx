This page is for a judge who wants to know where the questions come from, and what keeps a bad
one away from a child.

The bank holds converted Khan Academy items and Alfik Matematyczny tasks. Each item keeps its
source credit and licence. The API reaches the bank 2 ways only. It invokes the bank's own
search Lambda, and it reads a question's body from the content bucket by id. An id that starts
with `alfik_` is an Alfik task. Any other id is a Khan item.

A lesson takes only a lesson-ready question. Ready means the bank checked that the item compiles,
that its key grades its own answer, that every picture loads, and that the page draws it without
an error. An item the bank has not checked waits. An item a person flagged is out. The bank
searches by topic, grade, language, and question type, so a draft can ask for the types a child
needs. Questions embed with OpenAI `text-embedding-3-large` for that search, a call whose prompts
pass a name guard first.
