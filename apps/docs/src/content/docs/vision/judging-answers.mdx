When a child explains something in their own words, a model would judge the answer against
criteria written before the task, and the child would never read a bare „wrong".

## How it works

### Today

A typed explanation is kept without a verdict. The product's code judge refuses this kind of
answer on purpose. Code decides only one small thing: an empty answer, or one under the task's
minimum length, asks the child for a little more.

### Vision

A tutor model gives 1 verdict per criterion, each with a reason, and keeps the version of the
criteria it used. A parent can see what was asked and why. Spelling slips never fail a criterion
about meaning.

### What the child reads

The feedback is short and kind. It names one thing that's good or one next step, and never says
a bare „wrong".

## Limits

- **It's tested on invented answers only.** 2 Meta models agreed with the team's own labels on
  about 19 of 20 answers the team wrote ([E7](/experiments/e7/)).
- **A reason isn't checked against the child's words.** E7 counted a reason when it had 3 words
  or more.
- **Both models made the same false „wrong"** on 1 borderline answer ([E7](/experiments/e7/)).
