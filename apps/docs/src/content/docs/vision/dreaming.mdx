This page is for a judge asking how a parent hears about progress: not a dashboard of scores,
but a short report that says what moved, what needs attention, and what Jadwigo proposes next,
written only from what code has counted.

The split is the point, and it is already how `make dream` works. Code computes the digest: the
counts, the skills that moved and the attempts that moved them, the mistake classes, the brief,
each goal's standing, and at most 3 proposals. A model then writes only the narrative a parent
reads, in Polish or English, citing the digest's skills and attempts, restating none of its
numbers wrongly and naming no level. Code checks the narrative against the digest before it can
be saved, and a proposal changes nothing until the parent accepts it.

<Diagram name="dream" caption="Code digests, AI narrates, the parent decides." />

The vision is that pass running on a schedule: each week, per learner, ending on the parent's
learner page beside the goals it talks about. [E3](/experiments/e3/) runs the whole chain on the
12 invented learners, with the narrative written and judged on the contributor model through the
Meta API, and shows what still breaks: mostly the narrative's shape, not its facts.
