This page is for a judge asking how the bank reaches the next grade: new question sets are read
and enriched by Meta models, indexed for search, and held to a golden-set gate before a lesson may
use them.

<Diagram name="bank-pipeline" caption="The slice flow, from a source library to a gated index." />

The first slice is live: Khan maths for grade 3 in Polish and English, 143 sets and 2,738
questions, enriched on `muse-spark-1.3-contributor` for $2.57 (sets) and $1.22 (items) and
indexed at 1,892 vectors. Growing means running the same steps again for a new grade or a new
library, and E4 priced them: enrichment projects to $26.52 per 1,000 sets, golden labels to
about $2 to $3 per 100 needs, and a scored search run to about $0.04 per 100 needs of OpenAI
and Voyage calls. The money is not the constraint. A person's review is: every enriched field
carries `reviewed: false` until a person reads it, and the fields where the 3 drafts disagreed
wait in 1 file for that read.

What stays fixed as the bank grows:

- **Source fields are never rewritten.** A model writes only under `enrichment`, with the model
  named on every field and the source words each claim rests on. Code drops a claim whose quote
  is not in its source.
- **Needs never come from a source's own titles.** A need written from a page's title would find
  that page and prove nothing, so needs come from the curriculum, and the golden split is frozen
  once with a fixed seed.
- **Nothing is indexed before its licence is settled.** Khan's terms (CC BY-NC-SA 4.0, named on
  every page) and Alfik's were each ruled on by the owner first. A third library needs the same
  ruling, a reader that writes the same set page, and its credit line in the schema.
- **The gate decides, on tune, before holdout is read.** E5 showed both edges: a grown index
  that finds more and abstains less is blocked until a person reads the gaps, and a stale
  holdout baseline blocks judgement rather than passing quietly.

The next slices are already shaped: another Khan grade reuses every tool and changes only its
input file, output folder, needs and a golden set of its own (grades 1 to 4 are the plan, and
Alfik Matematyczny is the second library, indexed beside Khan). The gaps in today's golden set
choose what to pull next: of the 215 needs, 127 have no set graded relevant, and the curriculum
outcomes they cite, such as reading and ordering numbers to 1000, are the shopping list. What
is not yet measured is size: the search service builds its keyword corpus in memory at start,
the vector stage keeps its best 300 vectors a query, and neither has been read at thousands of
sets. The gate is how each growth step proves search still works before a child sees a question
from it.
