This page is for a judge following one goal round its loop: a parent names what to learn, lessons
gather the evidence, the report shows where it landed, and the next goal starts from there.

A goal in Jadwigo is a parent's own words plus the skills it needs. Lessons drawn for it write
evidence back, the fold turns that evidence into levels and due dates, and a report tells the
parent what moved, what needs attention and what it proposes next. A proposal changes nothing
until the parent accepts it, so the loop's steering wheel stays with the family.

<Diagram name="goals-loop" caption="One goal round its loop, the parent deciding at the join." />

Today the goal, its standing and the report exist; the loop is walked by hand.
[E1](/experiments/e1/) folds the evidence, [E2](/experiments/e2/) draws the next lesson for a
goal's brief, and [E3](/experiments/e3/) writes the report's words. The vision is those 3 steps
running in turn, each week, with the parent's yes at the join.
