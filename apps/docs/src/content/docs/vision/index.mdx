The demo is one lesson from one photo. The vision is what happens after it: Jadwigo keeps
teaching the same child, with more questions to draw from, and reads answers a child writes in
their own words.

None of this is in the product yet. Each area was tried in an experiment on Meta's Muse models,
with invented learners and invented answers only. The table says what each run showed, including
what didn't work.

## Every area

| Area | What it would do | What the experiments showed |
| --- | --- | --- |
| [The learning loop](/vision/learning-loop/) | Turn each answer into what the child knows, draw the next lesson from it, and write the parent a weekly report. | The fold works on 12 invented learners ([E1](/experiments/e1/)). The drawn lessons fit poorly, at 2.39 of 5 ([E2](/experiments/e2/)). 1 of 12 reports passed the code check ([E3](/experiments/e3/)). |
| [Growing the bank](/vision/growing-the-bank/) | Read new question sets, enrich and index them with Meta models, and test search before a child sees them. | Enriching the first 143 sets and their 2,738 questions cost $3.79 ([E4](/experiments/e4/)). The search test blocks the newer index, because it declines fewer questions it should decline ([E5](/experiments/e5/)). |
| [Judging answers](/vision/judging-answers/) | Mark a child's own-words answer against criteria set before the task, kindly. | 2 models agreed with the team's labels on about 95% of 80 invented answers ([E7](/experiments/e7/)). |
