# dl-e8ov.5.38: wave 1 plan, a parent's request becomes a drafted lesson through jw MCP

Epic `dl-e8ov.5.38`. Wave label `wave:dl-e8ov.5.38-1`. The owner asks Claude Code with `jw mcp serve`
registered for a lesson in plain words ("6 multiplication questions, klasa 3"). They get a card per
question: the prompt, the key, the 4 help rungs and the twin, the source and credit, and why the
draw picked it. Then `make lesson-import FILE=<draft> ENV=dev` puts it on jadwigo-dev and it plays
at `/play/<assignment>`. The tools read, draw, assemble and check. The calling agent writes the help
rungs, on the parent's own subscription.

## What the code gives the lanes

- `packages/lesson-import/src/lesson-file.ts`: a step is `id, question_type, skill_ids, based_on,
  say, question{family, data, key, help}, credit`. `help.twin` is a question plus `say`. The rungs
  the contract keeps are `look, boost, almost, worked` (`packages/contracts/src/families/help.ts`),
  and `compile.ts` turns the twin into a spare question.
- `compileLessonFile` already writes the assignment: `featuredAssignmentId(file.id)`, audience
  `anyone`, identity `none`. The id is deterministic, so the `/play/<assignment>` path is known
  before the import runs.
- The `Makefile`'s dev seed target already resolves jadwigo-dev's pooler URL and jadwigo_api's
  password and retries 28P01. `PROD_GATE` refuses the prod project from a session. The guard's
  `DB_TARGET` (`.claude/hooks/guard.ts`) names the 4 `db-*` targets only.
- The converted items file (david-learns `media/khan/converted.json`, gitignored) is
  `{generated_by, licence_note, items}`. An item is `id, family, problem_type, question, spec{data,
  family, help, id, key, phase, question_type, say}, credit{checked, original_lang, ref, source,
  url}`. Its credit has no `licence`; the file's `licence_note` holds it.
- `apps/cli/src/jw/draw.py`: `draw()` returns `Draw{kind, rule, rule_settled, questions[Drawn{item_id,
  set_id, problem_type, text, skill, reason}], left_out}`. `rule_settled` stays false.
- Set pages: `jadwigo-bank/sets/khan/math/grade-3/`, 143 sets and an `index.json`.

## Lead decisions

1. `lesson_check` reaches the TypeScript parser by subprocess: `jw` runs
   `bun packages/lesson-import/src/check.ts <file> --json` and reads `{ok, errors[{step_id,
   message}], play_path}`. A Python port would drift from the parser. The repo root comes from a
   setting, `JADWIGO_REPO_DIR`, defaulting to the checkout `jw` was installed from. `apps/cli`
   still imports nothing of ours.
2. `make lesson-import FILE=<file> ENV=dev` adds no new secret handling: it reuses the dev seed
   target's block, factored into one shared recipe, and runs
   `bun run --cwd packages/lesson-import import <file>`.
3. The assignment keeps `audience anyone, identity none`, what compile writes today and what
   `/play/<assignment>` plays without login. The bead said `pick`; pick needs a learner list the
   anonymous play path has no use for.
4. Credit comes back in the contract's `Credit` shape: `licence` from the item, else from the
   file's `licence_note`, and an error when neither has it. The Polish conversion writes `licence`
   on every item.

## Stop rules for a lane

- No lane writes to jadwigo-dev or jadwigo-prod, publishes, merges or runs `gh pr ready`. The owner
  readies a PR; md's merge steward reviews and merges it.
- items-pl stops when a Polish item's ids, keys or numbers differ from its English twin, and
  reports the list. cli stops when an item is not already in family shape. import and compose stop
  when a change to `packages/contracts` is needed.
- No Khan item text in a test or a fixture: fixtures are our own small bank's shape.
