# dl-a38n: wave 1 plan, the live lesson builder

Epic `dl-a38n`. Wave label `wave:dl-a38n-1`. The owner drafts a lesson through `jw mcp serve` in
a Claude Code session and watches it render at `/playground/lesson` as it is drafted, step by
step, with the check's findings pinned to each step; a comment on a step reaches the session
through an MCP channel and the session's answer and its tool calls show on the page. The design is
`docs/research/live-lesson-builder.md`, read it first.

## Lead decisions

1. **The draft is a file in a stable directory.** `JADWIGO_DRAFTS_DIR`, a jw setting with the
   default `~/.local/state/jadwigo/drafts`, replaces `tempfile.gettempdir()/jw-lessons` once `.10`
   lands. `lesson_draft` writes `<draft_id>.json` on every call and `lesson_check` rewrites it on
   every call, empty rungs allowed; the check's output is written beside it as
   `<draft_id>.check.json`. The page lists the directory and shows the newest draft, with a picker.
2. **Findings, not errors.** `check.ts --json` returns `findings: Finding[]`, `{step_id, path,
   level: "error" | "warn", rule, text, fix}`, everything it can find; `ok` is "no error". The old
   `errors[{step_id, message}]` stays for one release. The `Finding` type lives in
   `packages/lesson-import/src/findings.ts` (step 0 stub).
3. **The adapter lives in apps/web**, `apps/web/src/playground/lesson/adapter.ts`, beside `specOf`.
   `lesson-kit` may not import `lesson-import`, and does not need to.
4. **Browser-safe parse.** `packages/lesson-import` exports `parseLessonFile` and the file types
   from an entry with no `node:crypto` (`compile.ts` keeps it; split the import, or use
   `crypto.subtle`).
5. **One Vite plugin, two files.** Step 0 lands `apps/web/dev/builder-plugin.ts`, a skeleton that
   calls two hooks, `draftWatch` (`apps/web/dev/draft-watch.ts`, web lane) and `ask`
   (`apps/web/dev/ask.ts`, bridge lane). `vite.config.ts` loads it only when `command === "serve"`.
   `process.env` is read only in `apps/web/src/config.ts` (the grit rule), so the drafts directory
   and the session id reach the plugin through a function there.
6. **The page has slots.** Step 0's `apps/web/src/playground/lesson/LessonBuilderScreen.tsx`
   mounts `<CommentsSlot/>` and `<ActivitySlot/>` from `slots.ts`, both no-ops until the bridge
   lane fills `comments/` and `activity/`. The web lane never edits those two folders or
   `slots.ts`; the bridge lane edits nothing else under `lesson/`.
7. **Bridge code in `tools/builder/`**: `channel.ts` (the server), `launch.ts` (mints the session
   uuid, exports it, runs `claude --session-id <uuid>
   --dangerously-load-development-channels=server:jadwigo-builder`, refuses to continue when `ps`
   shows no flag), each with a test; `make builder` runs the launcher. `tools/` imports nothing of
   ours, which holds: the channel reads and writes JSONL under `JADWIGO_DRAFTS_DIR`
   (`<draft_id>.asks.jsonl`, `<draft_id>.replies.jsonl`) and never imports a package.
8. **Keys are visible** on this page, as on `/playground` today. Nothing here reaches `/play`.
9. **Workstreams.** The epic is cross-workstream and sits in the meta project. Each child carries
   one workstream label and the epic as its parent.
10. **Hand-backs** after the lanes stop go to the lead session, parked on
    `md merge-steward inbox --wait`. Lane PRs target `lesson-builder-lead` until step 0 merges.

## Briefs

A lane's brief is its beads: scope and the paths in `--description`, the owner's words and the
decisions in `--design`, done-when as commands in `--acceptance`. The lead hands each lane its
whole queue at once and waits for an acknowledgement. The lane works its queue in order, one PR
per bead, titled `<id>: <what>`, draft until `make check` is green, then `gh pr ready` and
`gh pr merge --auto --squash`, and notes on the bead what ran and what did not. The steward
closes the bead when the PR merges. A lane ends its session with one word, `DONE`,
`DONE_WITH_CONCERNS`, `NEEDS_DECISIONS` or `BLOCKED`, and the PR links.

## What the wave changed, for the next one

- **Every lane PR against the step-0 branch merged in seconds, unreviewed.** `lesson-builder-lead` had no
  required checks, so `gh pr merge --auto --squash` took #269, #271, #273, #277, #281, #287 and #291 the
  moment they went ready, and #267 became step 0 plus seven beads, reviewed as one. Filed as `dl-5ssh.101`.
  Until it is fixed: a lane PR against a step-0 branch stays a draft with no `--auto`; GitHub retargets it
  to `main` when step 0 merges; then merge `origin/main`, `gh pr ready`, `gh pr merge --auto --squash`, and
  check the auto flag again, because a retarget or a draft toggle clears it.
- **`JADWIGO_DRAFTS_DIR` has one rule on every side** (from #276's red review): the environment only, never
  jw's operator file; a leading `~` expands to HOME; the default is `~/.local/state/jadwigo/drafts`. jw
  (#276) and `tools/builder/config.ts` (#304) both follow it. jw creates the directory `0o700` and guards
  `title` and `reasoning` with `pii.guard` (an optional `names` input on `lesson_check`).
- **`key-in-say` is a warn** and skips an answer that is also an operand in the say ("10 − 5" with key 5),
  from #280's red review. `empty-rung` is skipped when the file's language does not resolve.
- **The page never dies on a bad step.** `@jadwigo/lesson-import/file` has `parseLessonFileLenient` and
  re-exports `Finding` and `worstLevel` (#302), and the page draws a skipped step as a card (#303).
- **Seams that were decided after a lane had merged** (`draftsDir()` delegating to `tools/builder`, the
  watcher skipping `.jw/` and `*.part`, `draft_id` on each `CommentsSlot`) cost a follow-up bead each
  (`.17`, `.19`). Next time step 0 names every seam before a lane starts, including the drafts
  directory's resolver and the dotfiles a watcher must skip.
- **A lead in a plain worktree has no steward inbox** (`md merge-steward inbox --wait --epic` needs
  `md delegate`); PR state was watched by hand. Cut the lead's worktree with `md delegate` next time.
- Open after the wave: `.18` (launcher hint quotes the README line), the owner decisions `.3` to `.6`,
