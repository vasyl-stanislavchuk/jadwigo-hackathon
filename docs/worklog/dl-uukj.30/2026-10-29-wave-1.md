# dl-uukj.30: wave 1 plan, lesson review

Epic `dl-uukj.30`. Wave label `wave:dl-uukj.30-1`. After a lesson, the child opens any question on
the end list and sees it again: the answer given, a mark on each part, and the right answer shown
directly where it was not right. The parent opens the same step from the attempt's page, with every
try, its time, the help used and the mistake class in plain words. One review step serves both.

## Shared paths

- `packages/contracts`, `packages/api-client` and `packages/copy` change only in the lead's PR. A
  missing field or copy key is a message to the lead.
- Every lane PR targets `lead/dl-uukj.30` until it merges, then GitHub retargets it to `main`. A
  stack updates by `git merge`, never by rebase.
- The lead keeps `md merge-steward inbox --wait` and takes every hand-back once a lane stops.

## Stop rules for a lane

The repo's: the same step failed 3 times with no new information; "done when" needs a file the lane
does not own; a contract disagrees with the issue; a test the lane did not write fails; the next
step is a migration or a paid call. The stop note is 4 lines on the issue.
