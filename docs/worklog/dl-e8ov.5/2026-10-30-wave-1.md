# dl-e8ov.5: wave 1 plan, the learner knowledge base foundation

Epic `dl-e8ov.5`. Wave label `wave:dl-e8ov.5-1`. Step 0 is `dl-e8ov.5.1`, on branch
`dl-e8ov.5.1/learner-knowledge-step-0`. The wave builds the knowledge base that understands each
child: skills a pod owns, seeded from a shared curriculum; mastery per skill folded from the
child's judged tries; a brief that says what to reteach, review, start, recheck; a report ("the
dream") code works out and an AI workflow narrates for the parent; and the parent's learner page
that shows it. The design is `docs/research/goals-and-mastery.md` and
`docs/research/curriculum-and-skills.md`; the research behind the shapes is david-learns'
`docs/research/learner-knowledge-base.md` and `learner-knowledge-base-on-aws.md`.

## How md's brain maps onto a learner's knowledge base

| md project brain | The learner's knowledge base |
| --- | --- |
| the charter: outcome, values, standing questions | the learner and goals in the parent's words; 2 standing questions, `skills_standing` and `next_focus` |
| sources the loop pulls | judged tries in `learner_skill_evidence` (measured); parent notes later (said) |
| `decisions/`, promoted only by a person | goals and skills the parent confirmed; proposals the parent accepted |
| `reports/<date>.md`: headline, direction, verdicts with citations, proposals, asks, a reuse gate | `learner_report`: code's `digest` and `inputs_hash`, the AI's `narrative`, the parent's `decisions` |
| the project page | the parent's learner page in `apps/web` |
| pull, probe, report, decide, page tick | finish or claim, mastery rebuild, `POST reports`, `/jadwigo-report-write`, the parent decides |
| the report skill never recomputes a number and cites every claim | the narrative restates only the digest's numbers, cites skill codes and attempt ids, names no level |

## Shared paths

- `packages/contracts`, the `Store` interface and `store.contract.ts`: the lead's only. A gap is
  a note on the lane's bead.
- `packages/store/src/memory.ts`: step 0 fills it; store-api fixes only.
- `bun.lock` and `package.json` `"//"` blocks: only core adds a dependency (`ts-fsrs`).
- `Makefile`: cli adds the `dream` targets; store-api adds nothing there (the seed rides
  `make db-seed`).
- `ParentScreen.tsx`: web touches one mount line; `dl-e8ov.2.7` is open on the same file.
- `infra/terraform/main.tf`: step 0 only; `dl-e8ov.2.42` merges with it.

## Stop rules for a lane

- No lane writes to `jadwigo-dev` or `jadwigo-prod`, runs a migration on a real project, deploys,
  or runs the narrative workflow on anything but the throwaway learner.
- No real learner data in a prompt, a fixture or a test; invented names only.
- No level name, score, percentage, streak or countdown reaches a parent's screen or a report's
  narrative; counts are digits.
- A lane that needs a contract change, a Store method, or a file outside what it owns stops and
  tells the lead on its bead.
