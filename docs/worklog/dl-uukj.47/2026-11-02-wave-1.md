that says honestly what Jadwigo AI is doing: the parent's words in a bubble on the right, Jadwigo AI's

## Lead decisions

1. **Step 0 is one PR** (`dl-uukj.47.11`): the chat moves from `apps/web/src/playground/chat` to
   `apps/web/src/chat`, every copy key the lanes need lands (per `packages/copy/AGENTS.md`: types, pl, en,
   both review sidecars, `bun run messages`, `src/paraglide` committed, nothing in baseline), and the fold's
   chat message item carries `context`. Lanes chat and shell start when it merges; marketing and devloop
   start now.
2. **Ownership is by directory.** Chat owns `apps/web/src/chat/**` and all of `apps/web/src/parent/workspace/**`
   plus `apps/web/src/playground/workspace/**` (its dev route). Shell owns the rest of `apps/web/src/parent/**`
   and `packages/ui/src/primitives/{sheet,tabs}.tsx`. Nobody else edits `packages/copy`: a missing key is a
   message to the lead, who lands a copy-only PR.
3. **One run state.** `runPhase(turns, state, now)` in `src/chat/phase.ts` is the only source for the band,
   the folded strip, the lesson placeholder, the footer's status and the live region. "Utknęło" (stalled)
   is said before "nie udało się" (failed); failed only when the run or the channel says so.
4. **No reasoning row.** `model_response` carries no reasoning; "Tok rozumowania" is dropped until a
   contract seam exists. The plan card draws `RunView.plan` and waits on the engine emitting it
   (`dl-hin8.19`, not in the wave); it is tested on the golden log `plan-and-cite`.
5. **The context chip tells the truth.** It reads the last parent message's `context`, never the details
   panel's unsent choice, and is complete only once `dl-uukj.47.12` and `dl-z5ja.114` land.
6. **Seen without a paid call.** `/playground/workspace` (chat issue 1) renders the workspace on the
   in-process engine with `?pace=slow|stall|fail`; every chat PR carries screenshots from it, and the chat
   e2e points there. The paid walk with real Muse is the owner's, once devloop lands.
7. **Tool-line icons are decorative.** `aria-hidden`, with the state in text; never a `role="status"` per line.
8. **Motion only under `motion-safe`.** Nothing moves under `prefers-reduced-motion`.
