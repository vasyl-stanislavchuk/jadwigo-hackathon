# dl-5ssh.90: wave 1 plan, living docs at docs.jadwigo.pl

Epic `dl-5ssh.90`. Wave label `wave:dl-5ssh.90-1`. Jadwigo's API, MCP server and design system are
documented only in code. This wave builds `apps/docs`, a Starlight site at docs.jadwigo.pl whose
reference pages are generated from that code and fail CI when they drift.

The model is adam-calling's `docs-site`. There, the code generates the OpenAPI document, which is
committed as a snapshot that CI diffs, and a contract test pins the operation ids. The reference
pages are generated at build time and never committed; hand-written guides sit beside them; and
`llms.txt` and the raw spec are published for agents. Two of adam's gaps are closed here: the docs
build on every PR, and a guide may only name an `/api/...` path that is in `ROUTES`.

## The order

1. Step 0 (`dl-5ssh.90.1`) lands first. Until it merges, lane PRs target its branch or stay drafts.
2. The cli and exports lanes start now. The contracts, docs and infra lanes start once step 0 is pushed.
3. The docs lane's items 2 to 4 each wait for their own input: the `openapi.json` snapshot, the
   `mcp-tools.json` snapshot, and the subpath exports.
4. The CI job (`dl-5ssh.90.10`) follows the API reference, so its first run builds a real site.
5. The owner applies and publishes once the pages and the Terraform are merged.

Stacks update by `git merge`, never by rebase. Once the lanes end, the lead takes the steward's
hand-backs on every PR of this wave.

## Risks the lanes check first

- Starlight 0.42.6 peers `@astrojs/markdown-remark`, while Astro 7.4.2 and `starlight-openapi` use
  `markdown-satteri`. The docs lane starts with a trial build. If that fails, the fallback is a
  single `@scalar/api-reference` page, and the lead decides.
- Some schemas differ between input and output (coercion, defaults), so the generator names the
  input copy `<Name>Input`. `Seq` (`z.coerce.number().pipe(...)`) is a path parameter to check.
- `questionSearches` is `auth: "none"` at the gateway but takes the bank's shared read token. The
  OpenAPI document describes that token as its own security scheme, not as `bearerAuth`.
- `turbo --affected` doesn't follow plain file reads, so `apps/docs/turbo.json` lists the two
  snapshots as build inputs, and the CI job builds every time.

## Where it landed (2026-10-30)

Every lane's PR is on main, and docs.jadwigo.pl builds in CI on every code change. It is not yet
public: the Terraform apply and the first publish are the owner's (`dl-5ssh.90.12`, runbook
`docs/runbooks/docs-publish.md`).

| What | Where it comes from | What fails when it drifts |
| --- | --- | --- |
| API reference, 19 operations | `packages/contracts/openapi.json`, generated from `ROUTES` | the contracts snapshot test; a route without `summary` fails typecheck |
| MCP pages, one per tool | `apps/cli/mcp-tools.json`, from `jw mcp serve` | the cli snapshot test; the docs test until a new tool's output is documented |
| Token and question-type tables | `@jadwigo/ui/foundation.css`, `@jadwigo/lesson-kit/question-types` | the docs token test, with floors on each tier |
| Errors and access tables | `ERROR_STATUS` and `ROUTES` | rebuilt every build |
| Links and guide paths | the content pages | the links validator; `guides.test.ts` for `/api/...` paths |

The MCP pages and the design-system pages became lanes of their own (`lane:mcp`, `lane:design`)
so the three page issues ran in parallel. They landed one at a time, API, then MCP, then design,
because all three edit `SIDEBAR`, `MUST` and `apps/docs/package.json`.

Lessons the next wave can use:
- **A file read is not a dependency.** `turbo --affected` and turbo's cache only follow package edges
  and declared inputs. Every snapshot or source file a package reads by path needs a workspace
  edge or a `turbo.json` input, or a change to it skips the test (`#198`'s hand-back) or replays a
  stale green (`dl-uukj.32.14`).
- **A squash-merged base makes add/add conflicts** in every branch stacked on it. Merge the base's
  final tip first, then main, and keep your side where main has not touched the file since. The
  recipe is in `bd memories squash-stack-merge`.
- **A path pattern in a fence must be anchored.** `(^|/)dist/` also matched `node_modules/**/dist/`
  and silently switched off a library rule (`#190`'s hand-back). `tools/src/fences.test.ts` now
  plants that case.
