# dl-e8ov.2: wave 3 plan, parent login

Epic `dl-e8ov.2`. Wave label `wave:dl-e8ov.2-3`. Milestone 1 (login-free play of a featured lesson on
app.jadwigo.pl) shipped on 2026-10-28. Wave 3 starts parent login: after the results, an adult signs
in with an email code, adds the child and keeps the attempt the child just played. The design is
`docs/research/parent-login.md`.

## Shared paths

- `supabase/migrations`: the lead's migration is `20261029120000_parent_login.sql`. It applies after
  the sweep's `20261029090000_expire_unclaimed_attempts.sql` (`dl-5ssh.3.5`, merged), which deletes
  only attempts with no learner, so a claimed attempt is kept.
- `packages/contracts` changes only in the lead's PRs. A gap is a message to the lead.

## Stop rules for a lane

- No lane writes to `jadwigo-dev` or `jadwigo-prod`, sends mail, runs `terraform apply` or deploys.
  Those are the owner's.
- No real token, key or password in a file, a chat or an issue. The RS256 key in `packages/testing`
  is a test key made for this repo and signs nothing outside tests and local development.
- Every name follows `packages/contracts/RULES.md`.
