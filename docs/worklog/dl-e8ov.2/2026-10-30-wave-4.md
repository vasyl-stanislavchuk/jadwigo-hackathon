## Shared paths

- `packages/copy`: only the web lane adds keys this wave. The site lane writes its own pages'
  text in `apps/site`.
- `infra/supabase-auth/<env>.json`: only the infra lane writes it. The db lane's design note names
  the hook function, and the infra lane switches it on in `dl-e8ov.2.67`.
- `infra/Makefile`'s `web-deploy` also changes in `dl-n9fr.53` (`VITE_MEDIA_URL`). The infra lane
  merges with that change, it does not rebase over it.

## Stop rules for a lane

- No lane writes to `jadwigo-dev` or `jadwigo-prod`, runs `auth.sh apply`, `terraform apply`, a
  migration on a real project or a deploy. Those are the owner's.
- No secret in a file, an argument, an output line, a chat or an issue. `auth.sh diff` names a
  secret as set or missing.
- `email_optional` stays off for both providers: the no-email design depends on Supabase refusing
  that sign-in.
- A lane that needs a change outside what it owns, or a contract change, stops and tells the lead.
