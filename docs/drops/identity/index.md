# Jadwigo's identity: what it looks like, how it sounds, what its name says

## TL;DR

- **[Look](look.html):** options all built on Zeszyt, so the site and the lesson read as one product. **Zeszyt** is plain Andika. **Królewski zeszyt** is a Fraunces wordmark with a paper-cut crown, on cream. **Ślad** is a [Baloo 2](fonts/baloo-2-LICENSE.txt) wordmark with a trail of footprints that becomes the lesson's step bar. Each one is shown on the jadwigo.pl hero, on a phone and on a lesson card.
- **[Child, class, school](rings.html):** Jadwigo began at the Meta Global AI Developer Hackathon and grows by doing things that don't scale. Jadwigo goes first to one child, then his class, then his school. So each look is also tried on the link card a parent sees in the class chat, a printed invitation and a school poster.
- **[Voice](voice.html):** the same lines in each register: a calm guide, a kind teacher and a curious companion. A message for a parent to post in the class chat sits under them.
- **[Name story](name.html):** stories about a school's patron, Queen Jadwiga, each with and without a character, beside the family's own story on an "O nas" page.
- **[What the owner decides](decide.html):** the choices, each filed as an issue, with options and no pick.

## The brief: the lead messages

Every option is judged against the lead message, which the owner has yet to pick (`dl-w0b4.30`, from the go-to-market note). Each look's hero shows the lead it leans toward. Any look can carry any lead.
